# Wal Quartett – Project

Digital quartet game with 32 whale species.
Created on August 21, 2026.

---

## Files

| File | Description |
|------|-------------|
| `wal_quartett.html` | Interactive screen version (browser) |
| `wal_quartett_druck_pdf.html` | Static print template |
| `wal_quartett_druck.pdf` | Print-ready PDF (8 pages A4, 60×90 mm Rhommé) |
| `wal_facts.json` | 32 facts for each whale species (~100 chars) |
| `whale_images/` | 32 JPG photos (Wikimedia Commons, CC) |
| `PROJEKTPLAN_Wal_Quartett_Spiel.md` | Project plan for digital game |
| `TAGESPROTOKOLL_Wal_Quartett_2026-08-21.md` | Work log from creation date |

---

## Data fields per card

- **Name** (German + scientific)
- **Weight** (tons)
- **Length** (meters)
- **Lifespan** (years)
- **Dive** (minutes)
- **Fact** (~100 character description)
